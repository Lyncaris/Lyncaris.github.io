一、模型假设

在引入线性回归之前，我们首先要从机器学习开始追根溯源。机器学习最初的目标，是为了让机器根据数据自行学习，通过总结规律对于相关问题进行求解，并做出预测或判断。

其中，相关性作为一种极易总结或观察的规律，广泛且大量分布在人们的日常生活中。

比如经典的波士顿房价预测问题，房价与面积总是呈现正相关的趋势；运动量与能量消耗也呈现为正相关；烟草与健康间则往往呈现负相关……

因此，很自然想到了以线性模型作为总结规律的首选假设。其实还有个原因就是因为它真的很简单

对于给定的任意问题，我们先行假设其满足某种线性关系，即因变量 yyy 依赖于自变量 xxx 的变化而变化。则可构造以下线性模型：

y=wx+by=wx+b y=wx+b

  • w：权重，参数
  • b：偏置，参数

由于我们尚不清楚该问题究竟满足怎样的线性关系，事实上就连满不满足线性关系都还只是假设，因此暂且用未知参数www代表斜率。

那么，假设 yyy 与 xxx 之间确实满足 y=wx+by=wx+by=wx+b 的关系，则对于问题中的真实样本，每一个样本的输入xxx都必然能够得到准确的输出 yyy ……吗？

答案是否定的，事实上，真实世界的数据与理想情况下的推导间存在不小的偏差，一般我们将其称为误差。比如说，采集样本数据时笔误写错了数字，又或者测量设备本身就不够精确……总之这个世界的上帝总是在掷骰子，谁也不知道哪片雨林里的蝴蝶振振翅膀就会影响到明天的天气预报，因此真实的样本数据几乎不会百分百等于假设模型预测出来的结果。但也绝对不会差太多！误差只会是极小的，否则我们的预测就没有意义了。

总之，由于预测输出并不能严格等同于样本输出，那么显然我们的线性模型就不能直接使用yyy来表示了，因此则可得到如下线性模型：

y^=wx+b\hat y=wx+b y^​=wx+b

  • y^\hat yy^​：预测值

也就是说，y^\hat yy^​ 是我们使用输入 xxx ，根据已有样本数据总结出来的规律而预测得到的输出，或者更确切的说，是预估。

这就好像玩跳一跳那样，当我们玩多了以后，大概就能预估出需要蓄力多久才能跳出多远的距离，这种预估就是基于已有经验总结出来的规律，也就是手感。

此前我们所做的一切假设都是基于如此，我们假设问题满足某种理想化的线性关系，并以此构造出了线性模型 y^=wx+b\hat y=wx+by^​=wx+b 。在理想情况下，我们认为对于任意的样本xxx都符合这样的规律，并且能够得到对应的 y^\hat yy^​ 。当然实际情况中会因为各种莫名其妙的原因出现误差，但不论如何偏差，真实样本所测得的 yyy 总是大致符合这种规律。

所以我们将其称之为线性回归，线性指的是线性模型，回归则是为了强调任意yyy都具有向y^\hat yy^​这种规律，也就是线性模型，靠近归拢的趋势。

说得再直白些，其实就是一元一次函数。那么为什么我们还要在这么简单的地方大费周章呢？因为如果不提前讲清楚概念的话，无法引出下文的损失函数，更讲不清损失函数是什么。

二、损失函数

我们已经完成了模型假设，将 y^=wx+b\hat y=wx+by^​=wx+b 确定为线性回归模型，但尚未确定模型参数 www 、bbb 的具体取值。因此为了得到确切的参数，在此引入损失函数的概念。

具体而言，损失函数是用于量化模型预测值 y^\hat yy^​ 与真实值 yyy 之间差异或误差的函数，以此衡量模型的准确性。因此可以通过最小化损失函数得到模型参数的最优解。

损失函数的选择取决于假设模型的构造，对于线性回归模型，一般选择均方误差函数求解模型参数。

均方误差函数（MSE）：

L=1n∑i=1n(y^i−yi)2L=\frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^2 L=n1​i=1∑n​(y^​i​−yi​)2

  • LLL：损失函数（Loss FunctionLoss \ FunctionLoss Function）
  • nnn：样本规模
  • y^i−yi\hat y_i-y_iy^​i​−yi​：预测值与真实值间的误差
  • y^i=wxi+b\hat y_i=wx_i+by^​i​=wxi​+b

顾名思义，均方误差的意思就是将误差平方后再取均值。下面对均方误差函数简单解读一下：

我们知道，误差就是预测值与真实值之间产生的数值偏差，因此假设共有 nnn 个样本，那么对于第 iii 个样本，其误差很容易表示为：

y^i−yi\hat y_i-y_i y^​i​−yi​

由于我们希望得到尽可能拟合所有样本数据的线性模型，因此对于误差的计算就不能局限于单个样本间的差值 y^i−yi\hat y_i-y_iy^​i​−yi​ ，而要统计所有误差数据。

一个很容易想到的统计方法就是将所有样本误差统一相加，即：

L=∑i=1n(y^i−yi)L=\sum_{i=1}^n(\hat y_i-y_i) L=i=1∑n​(y^​i​−yi​)

但这样做有一个明显的bug，那就是对于误差 (y^i−yi)(\hat y_i-y_i)(y^​i​−yi​) ，其正负并不确定

(y^i−yi){＞ 0＜ 0(\hat y_i-y_i) \begin{cases} ＞ \ 0\\ ＜ \ 0\\ \end{cases} (y^​i​−yi​){＞ 0＜ 0​

那么样本中的正误差就会与负误差相抵消，相当于这些样本的误差就统计不到了，这并不是我们想要的效果。当然不难想到，可以将单个样本的误差 (y^i−yi)(\hat y_i-y_i)(y^​i​−yi​) 平方或取绝对值，通过消除负数项以达成目标。

同时需要注意，相较于绝对值而言，平方这种更加连续的形式显然更利于求导，（事实上选择平方项构造损失函数还有更加巧妙的作用，但是这里暂不展开，具体详情会留到后面详细讨论，以免发散思维）由于我们后面需要通过求导更新参数，因此选择平方统计：

L=∑i=1n(y^i−yi)2L=\sum_{i=1}^n(\hat y_i-y_i)^2 L=i=1∑n​(y^​i​−yi​)2

由于我们统计误差的方式里既有求和又有平方，两项操作会导致计算出的误差值非常之大，所以最后对这个超级大的误差值取均值得到：

L=1n∑i=1n(y^i−yi)2L=\frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^2 L=n1​i=1∑n​(y^​i​−yi​)2

有些教程里的损失函数还会更进一步：

L=12n∑i=1n(y^i−yi)2L=\frac{1}{2n}\sum_{i=1}^{n}(\hat y_i-y_i)^2 L=2n1​i=1∑n​(y^​i​−yi​)2

添加了一个常数 12\frac{1}{2}21​ ，这样做的好处是，对 LLL 求导后这个新增的 12\frac{1}{2}21​ 正好可以被约掉，看起来会更简洁些。

三、梯度下降

有了损失函数，我们就可以求解假设模型中的那些未知参数了。

首先，我们现在已经有了一个假设模型——线性回归：

y^=wx+b\hat y=wx+b y^​=wx+b

同时，我们还刚刚确定好了损失函数：

L=1n∑i=1n(y^i−yi)2L=\frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^2 L=n1​i=1∑n​(y^​i​−yi​)2

如果不嫌麻烦的话，我们还可以把线性模型带入到损失函数中写的更复杂些：

L=1n∑i=1n[(wxi+b)−yi]2L=\frac{1}{n}\sum_{i=1}^{n}[(wx_i+b)-y_i]^2 L=n1​i=1∑n​[(wxi​+b)−yi​]2

  • xix_ixi​：样本值，输入
  • yiy_iyi​：真实值，输入
  • www：权重，参数
  • bbb：偏置，参数

尽管看起来更复杂了，但写的更详细些对于理解公式是有帮助的，这样我们可以很明显看出来需要更新的参数依旧是只有 www 和 bbb ，而且很明显 www 和 bbb 会影响到损失函数 LLL 的最终结果。

我们希望最终得到的线性回归模型误差尽可能小，也就是希望损失函数能够尽量取最小值，同时又由于损失函数会受到 www 和 bbb 的影响，因此可以通过对损失函数进行某些操作来得到最终确切的 www 和 bbb 。

这里的某些操作……就是梯度下降法。

先简单观察一下之前得到的损失函数：

L=1n∑i=1n(y^i−yi)2L=\frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^2 L=n1​i=1∑n​(y^​i​−yi​)2

虽然有些繁琐，但起码还是能够看出来这是一个二次函数。如果不好观察的话可以简单展开一下，比如设 n=3n=3n=3 ：

L=(y^1−y1)2+(y^2−y2)2+(y^3−y3)23L=\frac{(\hat y_1-y_1)^2+(\hat y_2-y_2)^2+(\hat y_3-y_3)^2}{3} L=3(y^​1​−y1​)2+(y^​2​−y2​)2+(y^​3​−y3​)2​

我们知道，对于一元二次函数，其求导后得到的是一元一次函数，且该导函数表示的是原函数图像上各点切线的斜率。更直观些说，一元二次函数求导后，其导函数描述了原函数变化速率的快慢。因此我们可以通过求导来求解一元二次函数的最值问题。

那么对于损失函数 LLL 这样的多元二次函数呢？显然我们可以对多元二次函数依次求偏导，其效果就等同于对该变量下的一元二次函数求导，同样可以得到该变量下的函数变化趋势。

由于我们希望更新的参数是 www 和 bbb ，因此就可以对损失函数依次求 www 和 bbb 的偏导，以分别得出 www 和 bbb 对于损失函数的影响。

以损失函数 LLL 为例：

L=1n∑i=1n(y^i−yi)2L=\frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^2 L=n1​i=1∑n​(y^​i​−yi​)2

依次对 www 和 bbb 求偏导：

∂L∂w=2n∑i=1n(y^i−yi)xi\frac{\partial L}{\partial w}=\frac{2}{n}\sum_{i=1}^n{(\hat y_i-y_i)x_i} ∂w∂L​=n2​i=1∑n​(y^​i​−yi​)xi​

∂L∂b=2n∑i=1n(y^i−yi)\frac{\partial L}{\partial b}=\frac{2}{n}\sum_{i=1}^n{(\hat y_i-y_i)} ∂b∂L​=n2​i=1∑n​(y^​i​−yi​)

其中，y^i\hat y_iy^​i​ 就是我们先前假设的线性回归模型：

y^=wx+b\hat y=wx+b y^​=wx+b

当然，如果看起来不够直观的话，也可以将 y^=wx+b\hat y=wx+by^​=wx+b 带入损失函数 LLL 后再求偏导。尽管这样写起来会更复杂些：

L=1n∑i=1n[(wxi+b)−yi]2L=\frac{1}{n}\sum_{i=1}^{n}[(wx_i+b)-y_i]^2 L=n1​i=1∑n​[(wxi​+b)−yi​]2

∂L∂w=2n∑i=1n[(wxi+b)−yi]xi\frac{\partial L}{\partial w}=\frac{2}{n}\sum_{i=1}^n{[(wx_i+b)-y_i]x_i} ∂w∂L​=n2​i=1∑n​[(wxi​+b)−yi​]xi​

∂L∂b=2n∑i=1n[(wxi+b)−yi]\frac{\partial L}{\partial b}=\frac{2}{n}\sum_{i=1}^n{[(wx_i+b)-y_i]} ∂b∂L​=n2​i=1∑n​[(wxi​+b)−yi​]

至此就会发现为什么有些教材在构造损失函数时热衷于添加一个常数项 12\frac {1}{2}21​ ：

L=12n∑i=1n(y^i−yi)2L=\frac{1}{2n}\sum_{i=1}^{n}(\hat y_i-y_i)^2 L=2n1​i=1∑n​(y^​i​−yi​)2

其目的在于，求导后会抵消这个常数项：

∂L∂w=1n∑i=1n(y^i−yi)xi\frac{\partial L}{\partial w}=\frac{1}{n}\sum_{i=1}^n{(\hat y_i-y_i)x_i} ∂w∂L​=n1​i=1∑n​(y^​i​−yi​)xi​

∂L∂b=1n∑i=1n(y^i−yi)\frac{\partial L}{\partial b}=\frac{1}{n}\sum_{i=1}^n{(\hat y_i-y_i)} ∂b∂L​=n1​i=1∑n​(y^​i​−yi​)

然后看起来会更简洁些，仅此而已。

倘若仍旧对于带有求和符号的求导不太理解，也可以将其展开求导，以便于观察。比如设 n=3n=3n=3 ：

L=(y^1−y1)2+(y^2−y2)2+(y^3−y3)23L=\frac{(\hat y_1-y_1)^2+(\hat y_2-y_2)^2+(\hat y_3-y_3)^2}{3} L=3(y^​1​−y1​)2+(y^​2​−y2​)2+(y^​3​−y3​)2​

将其分别对 www 和 bbb 求偏导可得：

∂L∂w=2[(y^1−y1)x1+(y^2−y2)x2+(y^3−y3)x3]3\frac{\partial L}{\partial w}=\frac{2[(\hat y_1-y_1)x_1+(\hat y_2-y_2)x_2+(\hat y_3-y_3)x_3]}{3} ∂w∂L​=32[(y^​1​−y1​)x1​+(y^​2​−y2​)x2​+(y^​3​−y3​)x3​]​

∂L∂b=2[(y^1−y1)+(y^2−y2)+(y^3−y3)]3\frac{\partial L}{\partial b}=\frac{2[(\hat y_1-y_1)+(\hat y_2-y_2)+(\hat y_3-y_3)]}{3} ∂b∂L​=32[(y^​1​−y1​)+(y^​2​−y2​)+(y^​3​−y3​)]​

四、参数更新

推导出偏导数公式以后，我们就可以利用偏导数对参数进行更新了。具体流程为：

  • 初始化参数：www 、bbb
  • 代入更新公式：

w新=w旧−η⋅∂L∂ww_新=w_旧-\eta\cdot\frac{\partial L}{\partial w} w新​=w旧​−η⋅∂w∂L​

b新=b旧−η⋅∂L∂bb_新=b_旧-\eta\cdot\frac{\partial L}{\partial b} b新​=b旧​−η⋅∂b∂L​

  • 循环更新

其中，η\etaη 为学习率，表示参数更新的速度。η\etaη 的取值根据实际情况而定，对于这样的参数我们将其称为超参数。

在首次初始化参数之后，www 和 bbb 会被随机赋值，并将赋值后的 www 和 bbb 作为旧参数代入更新公式，用于更新参数。

有关更新公式的理解可以参考以下示意图：

偏导数{＞ 0 ，切线斜率为正（红色）＜ 0 ，切线斜率为负（蓝色）偏导数\begin{cases} ＞ \ 0 \ ，切线斜率为正（红色）\\ ＜ \ 0 \ ，切线斜率为负（蓝色）\\ \end{cases} 偏导数{＞ 0 ，切线斜率为正（红色）＜ 0 ，切线斜率为负（蓝色）​

显然，当偏导数＞0时，旧参数位于谷底右侧，想要最小化损失就需要更新减小参数，使其向左侧靠拢；当偏导数＜0时，旧参数位于谷底左侧，想要最小化损失就需要更新增大参数，使其向右侧靠拢。

巧妙地在于，无论偏导数正负如何，更新公式均可成立：

w新=w旧−η⋅∂L∂ww_新=w_旧-\eta\cdot\frac{\partial L}{\partial w} w新​=w旧​−η⋅∂w∂L​

这里讨论的是最小化损失的举例论证，换成最大化损失同理。

在代入更新公式之后，只需要循环重复这个过程不断更新参数即可，更新过程中会根据预设置的学习率大小而影响收敛速度的快慢。

至此线性回归问题基本告一段落。

唯一值得思考的还有最后一个大问题，那就是：

  • 损失函数一定收敛吗？

在线性回归这里，损失函数的收敛问题被巧妙的构造方式一笔带过了，由于线性回归构造的损失函数是均方误差函数，而均方误差又恰恰是一个非常特殊的凸二次函数，对于半正定凸二次函数而言，其必有全局最小值，因此均方误差作为损失函数是一定收敛的。

这种巧妙源自于最初对于误差处理方式的选择上，我们选择了平方而非绝对值的形式处理误差，正是这种平方巧妙地将其构造为了一个凸二次函数。

但并不是所有的损失函数都可以有如此巧妙的构造，事实上有些时候想要构造出一个合适的损失函数是件非常头疼的事情。

因此一般而言，我们并不严格要求损失函数必须收敛，而是退而求其次放宽了一些要求。在实际构造损失函数时，我们通常希望该损失函数：

  • 有下界：不能随便到 −∞-\infty−∞
  • 最好有最小值：最小化问题有解
  • 可微或次可微：能算梯度
  • 梯度不要爆炸：数值稳定
  • 最好凸或强凸：容易优化，最好唯一解
  • 任务目标一致：损失小要真的代表模型好
